# JavaScript 玩學室

給 JavaScript 初學者的互動式學習網站。每個案例左側是概念說明，右側可以直接操作看到結果。

## 直接使用

不需要安裝任何套件，直接用瀏覽器開啟 `index.html` 即可。

## 包含的案例

- 變數與字串模板
- if / else 條件判斷
- 陣列、filter、reduce
- 函式與溫度轉換
- DOM 樣式修改
- click 事件監聽
- 表單驗證
- 待辦清單
- localStorage 瀏覽器儲存
- setInterval 倒數計時
- Canvas 滑鼠畫畫
- 隨機位置反應力遊戲

## 部署

這是一個不需要建置的靜態網站，可以使用 GitHub Pages、Netlify 或 Vercel 部署。GitHub Pages 只要將分支的來源設定為專案根目錄即可。
